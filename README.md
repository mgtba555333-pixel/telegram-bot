# PixelChief Android

A minimal Android starter for the PixelChief project with a GitHub Actions workflow that builds a debug APK.

## Build
Open **Actions → Build PixelChief APK** and run the workflow. When it completes, download the **PixelChief-debug-apk** artifact and extract `app-debug.apk`.

## Important
This is currently a starter/demo app. The Start button only toggles the demo UI; it does not yet automate Clash of Clans. Real game control, screen recognition, and device testing are not implemented.
